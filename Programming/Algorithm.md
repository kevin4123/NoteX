# 算法思维：从现实问题到可执行代码

## 核心理念

算法不是写代码的问题，而是**建模**的问题。本质上是将混沌的连续世界压缩成离散的可操作结构，这是一种**有意识的忽略**。

## 现实世界 vs 计算机世界

| 现实世界 | 计算机世界 |
|---------|-----------|
| 连续（时间、空间） | 离散 |
| 模糊边界 | 精确定义 |
| 不完整信息 | 有限表示 |
| 不确定性 | 可计算 |

## 问题转算法的标准流程

### Step 1: 界定问题
- 输入是什么？
- 输出是什么？
- 有什么约束？
- 成功的标准是什么？

### Step 2: 抽象变量
将现实对象转化为：
- 数值
- 状态  
- 关系
- 规则

**示例**：快递配送 → 订单集合S + 司机集合D + 成本函数C(i,j)

### Step 3: 识别结构类型
问自己：这更像什么？
- 排序问题
- 搜索问题  
- 图问题
- 动态规划
- 优化问题
- 约束满足

### Step 4: 选择数学工具
- 图 → 图论
- 最优 → 优化理论
- 决策过程 → 马尔可夫模型
- 连续系统 → 微分方程
- 不确定性 → 概率论

### Step 5: 离散化
- 时间离散化
- 空间离散化  
- 状态有限化
